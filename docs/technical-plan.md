# 中文矮人笑话站技术方案

日期：2026 年 10 月 22 日。以下保存早期技术讨论；当前实现和运行方式以项目 README 为准。首版采用 GitHub Pages，投稿使用 GitHub Issue；云函数投稿作为后续选项。

第一版面向中国大陆普通网络用户，收录约 50 张图片和 100 条文字，预计每天 10—100 次访问。产品定位是方便浏览、查找和投稿的中文矮人笑话收集站，以“仇恨之书”为主题。

建议采用 Astro 静态网站，加少量 TypeScript 和 CSS 交互；部署在腾讯 EdgeOne Makers（原 EdgeOne Pages），绑定自己的域名。已收录内容随网站发布，投稿通过一个独立的云函数接收。按目前的免费额度，这一规模可以让托管和存储费用保持在 0 元，域名另计。

## 托管和域名

EdgeOne 当前提供免费版，包含网站加速流量和请求，以及有额度的构建、函数和存储。官方说明现阶段免费政策和额度可能调整，不能据此承诺永久零成本。[官方常见问题](https://cloud.tencent.cn/document/product/1552/127458)

正式站点使用自己的域名：平台默认地址在大陆访问有预览时效或访问限制。尚无备案域名时，可先选“全球可用区（不含中国大陆）”并绑定自定义域名；使用大陆节点则需要完成域名备案。境外节点的大陆访问表现仍需上线前用实际运营商网络确认。[域名和加速区域说明](https://edgeone.cloud.tencent.com/pages/document/175191784523485184)

域名费用按注册和续费报价选择；已有可用域名时可使用其子域名。首次发布前验证电信、联通、移动及手机网络的首页、图片和投稿入口，尤其检查微信内打开的体验。

Cloudflare Pages 可作迁移备选，其免费版包含不限量的静态请求和流量。它的大陆访问效果同样需要实测。[Cloudflare Pages 套餐](https://pages.cloudflare.com/)

GitHub 也可以保存代码、文字和这批图片。若希望网站本身也放在 GitHub，可使用 GitHub Pages：GitHub Free 账户通过公开仓库发布静态站，使用免费的 github.io 地址，不必先购买域名。轮播、标签搜索和底部彩蛋仍由浏览器运行；Pages 本身不能运行接收投稿的服务端程序，投稿需要邮箱或外接接口。[GitHub Pages 说明](https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages)

GitHub Pages 的已发布网站上限为 1 GB，月带宽软限制为 100 GB，按上述内容规模和压缩图片后的访问估算可以容纳。大陆普通网络的实际可用性和速度仍需测试。[GitHub Pages 限制](https://docs.github.com/en/pages/getting-started-with-github-pages/github-pages-limits)

可先用 GitHub Pages 零成本试运行；若大陆访问体验不理想，再让 EdgeOne 从同一 GitHub 仓库自动构建发布。这样代码和内容仍保存在 GitHub，读者的网页与图片由 EdgeOne 提供，无需重做内容。[EdgeOne 导入 Git 仓库](https://pages.edgeone.ai/document/importing-a-git-repository)

## 容量和流量估算

以下是预算假设，尚未拿到实际图片文件。

| 内容 | 假设 | 估算大小 |
| --- | --- | --- |
| 50 张原始 PNG | 每张 0.5—2 MB | 25—100 MB |
| 100 条短文字与标签 | 短笑话和少量元数据 | 通常小于 1 MB |
| 50 张网页展示图 | 每张目标 0.1—0.5 MB，优先保证文字清晰 | 5—25 MB |

若每天 100 次访问，每次查看 20 张、每张平均 0.3 MB，则图片传输约为 100 × 20 × 0.3 × 30 = 18,000 MB/月，约 18 GB。每天 10 次访问时约 1.8 GB/月。以上不含装饰资源、爬虫和重复下载，也未扣除浏览器缓存收益。

页面首屏仅加载当前需要的图片，画廊延迟加载，轮播只预加载下一张。保留原始 PNG，展示图按实际效果选 PNG 或 WebP。脚本、字体和装饰资源随站部署，避免浏览页面时还必须访问其他站点。

当前 EdgeOne 免费额度包括站点下项目合计 5 GB 静态存储、单文件 25 MB，以及 1 GB Blob 存储，远高于这批内容的预计用量。[限制与配额](https://cloud.tencent.com/document/product/1552/132789)

## 内容放在哪里

| 内容 | 保存位置 | 更新方式 |
| --- | --- | --- |
| 已收录文字、编号、标签、来源 | 本地内容文件，构建后成为网页和检索 JSON | 整理后重新发布 |
| 已收录展示图 | 网站静态图片目录，与网页同平台分发 | 加入图片后重新发布 |
| 原始 PNG | 本地原图目录和备份 | 收录时保留 |
| 尚未审核的文字、图片投稿 | EdgeOne Blob，由云函数写入 | 审核后导入正式内容库 |
| 读者的轮播状态、已看列表 | 浏览器本地 | 不同步到服务器 |

浏览和搜索不需要查询数据库；新增内容也不需要立即推送给正在浏览的人。发布一次即可更新网站。Astro 默认能够在构建时生成静态页面，适合给每条笑话生成可分享的固定地址。[Astro 输出模式](https://docs.astro.build/en/reference/configuration-reference/#output)

## 页面和交互

首页以“仇恨之书”和随机笑话为中心，另有图片与文字的收录列表。分类、搜索、条目详情都从同一份内容库生成。

随机展示采用打乱队列：一轮看完前不重复，下一轮避免首条接上上一轮末条。图片默认 15 秒、文字默认 30 秒；保留上一条、下一条、暂停。计时从图片加载完成后开始，打开大图、投稿框或切到其他标签页时暂停，较长内容可单独延长时长。自动切换只作用于随机展示区，浏览列表保持位置稳定。

页面底部彩蛋采用“假页脚 + 下方隐藏的小舞台”：普通页脚下再留一段约 200—300 像素的可滚动空间，继续往下看才发现几名矮人够不到上方的页脚。可以点他们弹出一句“是谁把页脚挂这么高？记下来！”

彩蛋通过正常页面滚动和位移动画实现，不依赖浏览器的原生橡皮筋回弹。手机、鼠标和键盘都能发现；减少动态效果时仍能看到内容。收录列表使用分页或明确的加载按钮，避免无限滚动导致永远到不了底部。

## 编号和标签

正式编号按用户指定，从 0000、0001 开始递增。它标识一条收录内容，与排序、类别、标签无关；删除后不复用，改标签不改号。0000 与 0001 的日期保留在笑话正文中。

同一笑话的文字版和截图放在同一条目下；图片文件可以使用 0002-01.png。改编幅度较大、需要单独展示的版本另编新号，后续可用 variantOf 指向原条目。发现重复并合并时保留旧编号的跳转。

每条内容先保留以下字段即可：id、title、text、images、tags、source、createdAt；variantOf 仅在需要时填写。图片本身有对白时也录入文字，既便于搜索，也便于与已有文字笑话比较。

标签采用一个小型固定词表，例如：身高、胡子、精灵、矿洞、麦酒、记仇、谐音。每条通常选 2—4 个；投稿者可以建议标签，最终收录时统一名称。图片或文字属于呈现形式，不混进主题标签。

## 去重规则

标签用于分类和筛选疑似重复，不能作为判重依据。两个不同笑话完全可能拥有相同标签。

1. 文字先规范换行和多余空格，生成比较用指纹；完全一致时提示重复，保留原文不改写。
2. 图片计算 SHA-256，发现完全相同的文件；改尺寸、加水印或重截图不会命中这一检查。
3. 对修改过的文字和图片，以录入的对白、关键词及标签找候选，再由维护者看笑点是否相同。150 条规模下可以人工完成。
4. 同一内容的不同载体合并；有独立趣味的改编保留为关联版本。感知哈希或 OCR 在图片数量增大后再加入，不让相似度自动决定删除。

## 投稿入口和接收流程

桌面端右侧放一个窄悬浮按钮“添一笔仇”，点击才展开投稿抽屉。手机端使用右下角小按钮，打开后呈现整屏表单，避开图片内容和系统手势区。

第一版表单允许填写文字、上传一张图片或提供原帖链接，至少一种；昵称和标签建议选填。不要求注册。提交成功表示进入待收录箱，审核后才成为公开条目。

接收流程为：投稿表单 → Node.js 云函数 → Blob 待收录箱 → 维护者导出并检查 → 分配正式编号 → 加入静态内容库 → 重新发布。

文字元数据可作为 JSON 与附件一起存入 Blob，因此第一版无需再增加 KV 或关系数据库。Blob 适合接收用户文件，正式公开图片仍随静态站点分发。[Blob 官方文档](https://pages.edgeone.ai/document/blob-storage)

图片先限定单张 4 MB、PNG/JPEG/WebP，并在服务端验证实际格式、大小和文字长度；接口设置提交频率限制。待收录箱不公开，审核导出仅维护者可用。使用独立随机投稿号，成功保存后再返回回执，不在多人投稿时抢占正式递增编号。

当前云函数请求体上限为 6 MB，单张 4 MB 为表单开销预留空间。投稿量小的时候，函数与 Blob 预计可落在免费额度内；待收录箱按审核结果清理。[函数和存储配额](https://cloud.tencent.com/document/product/1552/132789)

## 实现顺序

先完成本地静态站与少量真实样例，验证仇恨之书、轮播、底部彩蛋、标签和条目编号。随后接通投稿与审核导出，再补齐首批内容。正式发布时选定域名和加速区域，完成大陆网络实测。

当前阶段不需要自购云服务器、实时推送、用户账号体系或大型内容管理后台。
